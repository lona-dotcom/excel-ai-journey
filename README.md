## 🧭 Vision du Projet

Ce dépôt n'est pas simplement une collection de scripts. C'est une **feuille de route progressive** et un **portfolio vivant** démontrant la transition d'un expert métier vers un **ingénieur orienté données et IA**.

L'objectif est de maîtriser l'écosystème complet : transformer des données brutes Excel en tableaux de bord dynamiques, puis automatiser ces processus avec Python, et enfin les augmenter avec des capacités d'Intelligence Artificielle (LLMs, Agents).

## 🗺️ La Feuille de Route (Phases 0 à 11)

Le projet est découpé en 12 phases stratégiques, allant de la configuration initiale à la construction d'un portfolio final de niveau production.

| Phase | Thème | Objectif Principal | Technologies Clés |
| :--- | :--- | :--- | :--- |
| **0** | **Setup** | Initialisation du projet, gestion de versions et structure propre. | Git, GitHub, VS Code |
| **1** | **Excel Avancé** | Formules complexes, validation de données, gestion des erreurs. | Microsoft Excel |
| **2** | **Power Query & Pivot** | Nettoyage, transformation de données massives et modélisation. | Power Query, Power Pivot |
| **3** | **Python & Openpyxl** | Automatisation des tâches répétitives et manipulation des classeurs. | Python, Openpyxl |
| **4** | **Openpyxl Avancé** | Mise en forme conditionnelle, graphiques et génération de rapports. | Openpyxl, Pandas |
| **5** | **xlwings** | Interaction bidirectionnelle entre Python et Excel (VBA vs Python). | xlwings, VBA |
| **6** | **Automatisation & Dashboard** | Création de pipelines automatisés et de tableaux de bord interactifs. | Streamlit, Automation |
| **7** | **Consolidation** | Synthèse des compétences acquises pour résoudre des cas métiers complexes. | Data Pipeline |
| **8** | **Fondamentaux IA** | Introduction aux LLMs et à l'ingénierie de prompt. | OpenAI API, Prompts |
| **9** | **Construction Agent IA** | Création d'agents autonomes capables d'interagir avec des données. | LangChain, Agents |
| **10** | **Projet Capstone** | Application réelle combinant Excel, Data et IA (Projet Final). | MLOps, Architecture |
| **11** | **Finalisation Portfolio** | Optimisation du code, documentation et mise en ligne professionnelle. | Clean Code, CI/CD |

## 🛠️ Stack Technique & Outils

- **Langages :** Python (Core), SQL (via Power Query/Dataflows), VBA (pour contexte).
- **Bibliothèques Python :** `pandas`, `openpyxl`, `xlwings`, `python-dotenv`, `streamlit`, `openai`, `langchain`.
- **Interfaces :** Jupyter Notebook / VS Code.
- **Data & BI :** Excel, Power Query, Power Pivot.
- **Versioning :** Git, GitHub (Workflow Branches / Pull Requests).

## 🚀 Installation & Utilisation

### 1. Prérequis
- Python 3.10 ou supérieur installé.
- Git installé.
- Un compte GitHub.
- *(Optionnel mais recommandé)* : Une clé API OpenAI pour les phases IA.
